# GenLayer Spinner Variants

20 minimal loading spinners for the GenLayer Portal. Black, white, purple. Pure CSS, zero dependencies.

## Concepts

| # | Name | Motion |
|---|------|--------|
| 01 | **Orbit** | Dots orbiting center point |
| 02 | **Pulse Ring** | Concentric rings expanding outward |
| 03 | **Breathing** | Hexagon scale pulse |
| 04 | **Neon Trace** | Light tracing hexagon edge |
| 05 | **Split** | Two halves separating and joining |
| 06 | **Dot Wave** | Wave of dots in sequence |
| 07 | **Radial Sweep** | Conic gradient rotation |
| 08 | **Morph** | Circle morphing to hexagon |
| 09 | **Lightning** | Electric arcs firing |
| 10 | **Stagger** | Bars fading in sequence |
| 11 | **Spin Bounce** | Rotation with bounce easing |
| 12 | **Sine Wave** | Animated sine waves |
| 13 | **Swirl** | Particles spiraling outward |
| 14 | **Glitch** | Horizontal glitch bars |
| 15 | **Progress** | Sliding progress bar |
| 16 | **Hex Fill** | Hexagon filling from bottom |
| 17 | **Dot Pulse** | Single pulsing dot with glow |
| 18 | **Circle Split** | Circle halves rotating |
| 19 | **Neon Glow** | Hexagon with neon glow pulse |
| 20 | **Typing** | Blinking cursor |

## Tech

- Pure CSS animations
- Zero dependencies, no JS required
- Each spinner < 1KB
- Respects `prefers-reduced-motion`

## Usage

Open `preview/demo.html` to see all 20 spinners with dark/light/purple background toggle.

Each spinner is self-contained in `spinners/XX-name.html`.
